# Technology icons

`src/data/technology-icons.json` contains twelve unmodified SVG paths from the official [Simple Icons](https://github.com/simple-icons/simple-icons) npm package, version 16.35.0. The upstream project distributes its icon collection under CC0-1.0; see the [included license](simple-icons-LICENSE.md) and individual brand guidance. The JSON records each upstream slug for traceability.

The site renders paths on the server using the existing accent color. No icon CDN or icon-library JavaScript is required. Every icon sits beside a visible technology label and is hidden from assistive technology to avoid repetition. SQL and technologies without an icon in this collection use small text initials. Methods such as feature engineering remain text-only. No skills were added to the verified data.
