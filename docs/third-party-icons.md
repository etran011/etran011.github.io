# Technology icons

`src/data/technology-icons.json` contains twelve unmodified SVG paths from the official [Simple Icons](https://github.com/simple-icons/simple-icons) npm package, version 16.35.0, plus Tableau and Microsoft Excel from version 11.15.0. The upstream project distributes its icon collection under CC0-1.0; see the [included license](simple-icons-LICENSE.md) and individual brand guidance. The JSON records each upstream slug for traceability.

Matplotlib, AWS, and Stata use unmodified self-hosted SVGs from [Devicon](https://github.com/devicons/devicon), retrieved October 16, 2026 (plain, plain-wordmark, and original-wordmark variants respectively). Their masks take the existing accent color. See the [Devicon license](devicon-LICENSE.txt). The AWS mark represents the verified EC2 environment without claiming additional AWS services.

Seaborn uses its official [dark-background logo mark](https://github.com/mwaskom/seaborn/blob/master/doc/_static/logo-mark-darkbg.svg), retrieved October 16, 2026, with its original blue tones. See the [Seaborn license](seaborn-LICENSE.md).

Paths render on the server and other assets are self-hosted. No icon CDN or icon-library JavaScript is required. Every icon sits beside a visible technology label and is hidden from assistive technology to avoid repetition. SQL uses a text mark because the language has no single canonical brand logo. No skills were added to the verified data.
